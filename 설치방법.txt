==============================================================
  로또 마스터 모바일 (홈 화면 앱) — 설치 방법
==============================================================

이 폴더의 파일 7개를 인터넷에 한 번 올려두면, 폰에서 그 주소를 열어
'홈 화면에 추가'로 앱처럼 설치할 수 있습니다.
설치한 뒤에는 인터넷 없이도 분석·번호 생성이 됩니다.
(인터넷은 '업데이트' 버튼으로 새 당첨번호를 받을 때만 필요)

올릴 파일 (7개 모두):
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

──────────────────────────────────────────────
■ 1단계. GitHub에 올리기 (무료, PC에서 약 5분, 처음 한 번만)
──────────────────────────────────────────────
 1) https://github.com 에서 무료 회원가입 후 로그인
 2) 오른쪽 위 [+] → [New repository]
    - Repository name: lotto   (원하는 영문 이름)
    - Public 선택 (무료 페이지 기능은 Public 저장소에서 동작)
    - [Create repository]
 3) 만들어진 화면에서 "uploading an existing file" 링크 클릭
    → 이 폴더의 파일 7개를 한꺼번에 끌어다 놓기 → 맨 아래 [Commit changes]
 4) 저장소 위쪽 [Settings] → 왼쪽 메뉴 [Pages]
    - Source: Deploy from a branch
    - Branch: main   /(root)  → [Save]
 5) 1~2분 기다린 뒤 같은 화면 위쪽에 나오는 주소를 확인
    예) https://내아이디.github.io/lotto/

──────────────────────────────────────────────
■ 2단계. 폰에 설치
──────────────────────────────────────────────
 [안드로이드]  크롬에서 위 주소 열기 → 화면의 [앱 설치] 버튼
               (안 보이면 크롬 메뉴 ⋮ → '홈 화면에 추가' 또는 '앱 설치')
 [아이폰]      반드시 Safari로 주소 열기 → 아래쪽 공유 버튼(□↑)
               → '홈 화면에 추가' → [추가]

 → 홈 화면에 '로또마스터' 아이콘이 생깁니다.
 → 설치 직후 한 번은 인터넷이 연결된 상태로 열어 주세요 (오프라인용 저장).

──────────────────────────────────────────────
■ 사용 팁
──────────────────────────────────────────────
 - 번호판: 한 번 누르면 고정(초록), 두 번 누르면 제외(빨강), 세 번 누르면 해제
 - 결과: [복사] [공유(카톡 등)] [CSV 저장]
 - 설정과 받은 당첨번호는 폰에 자동 저장됩니다.
 - 1회~1243회 당첨번호는 앱에 들어 있고, [업데이트]로 이후 회차를 받습니다.
 - 앱을 고친 새 버전이 나오면 GitHub에 파일만 다시 올리면
   폰 앱은 다음 실행(인터넷 연결 시) 때 자동으로 새 버전이 됩니다.

 ※ PC에서 미리 보려면 index.html 을 더블클릭해도 열립니다
   (이 경우 오프라인 저장·설치 기능만 빠짐).
 ※ 추첨은 매 회 독립 시행이며, 분석 결과는 당첨을 보장하지 않습니다.
